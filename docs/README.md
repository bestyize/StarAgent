## 两篇文档的关系

**白皮书**定义产品整体——包括二期才交付的真机操作能力，因此它描述的是完整蓝图。

**一期交互形态设计**只解决一期问题：在没有真机操作的前提下，产品靠什么立住。

分期口径是：**一期**先把"支持自定义大模型的、完善的 AI 智能体"做扎实（对话与多模态交互、记忆、任务托管、技能、渠道、模型自由）；**二期**让 Agent 长出双手，能真实操作用户手机。
