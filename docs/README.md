## 两篇文档的关系

**白皮书**定义 StarAgent 的**通用底座定位与长远架构蓝图**——覆盖桌宠机器人、智能家居中控、情感陪伴数字人与移动助理等多元形态，是整个技术栈的核心宪章。

当前以 KMP 开发参考实现，设计方向保持核心语义统一、执行机制可替换、依赖有明确归属。纯逻辑与极少依赖是长期理想，跨语言实现按实际需求推进；用无头样例和第二种运行形态验证解耦质量，允许明确、可控的工程依赖。

**一期交互形态设计**解决**官方移动端 App 旗舰形态**的落地问题：作为底座的第一个完整参考实现，如何在手机上呈现任务托管、记忆与多模态交互。

## 标记约定

白皮书中的核心原则与职责边界用于指导实现，架构图描述目标关系，路线图单独说明已落地与待推进事项。纯逻辑、极少依赖和低成本跨语言实现作为长期方向，按实际需求验证；性能与平台支持等尚需数据的结论以 **【待确认】** 标注，每篇末尾清单汇总关键待决策事项。
