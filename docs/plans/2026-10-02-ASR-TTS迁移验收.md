关键测试证据：

- 已安装模型真实推理：Piper 合成 → 读取实际采样率 → 必要时重采样 → SenseVoice 返回有内容的识别结果；Piper PCM 回调也产生有效音频，结束后释放引擎。
- Windows 音频输出：零样本静音测试验证 24 kHz / 22.05 kHz 播放、drain、阻塞写入取消和重新播放。修复了 22.05 kHz 分块出现奇数字节、截断半个采样的问题。
- MiMo 模拟网络：真实 ByteChannel/SSE 分块证明第一块音频在 DONE 到达前交付；覆盖鉴权/路径/JSON 转义、半采样、错误事件、提前断流。
- AppState 接线：首音先于 LLM 完成、完成后不重播、群成员/轮次顺序、语音失败仍保留完整文本、停止语音后 LLM 继续生成。
- 生命周期：取消后晚到的合成结果不播放；晚到识别结果不发送，也不会清除新的录音；试识别页退出关闭麦克风。
- 下载源实网检查：从固定版本下载 SenseVoice 与 Piper 词表，大小和 SHA-256 均匹配。未重新下载大模型权重。
